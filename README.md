🚀 Установка и запуск
Клонирование репозитория:

bash
git clone <url-репозитория>
cd my_online_store
Установка зависимостей:

bash
poetry install
Активация виртуального окружения:

bash
poetry shell
Настройка базы данных:

bash
python manage.py migrate
Создание суперпользователя:

bash
python manage.py createsuperuser
Запуск сервера:

bash
python manage.py runserver
Открыть в браузере:

text
http://127.0.0.1:8000/
📊 Модель данных
Product (Товар)

description - Описание

price - Цена

image - Изображение

category - Категория (ForeignKey)

created_at - Дата создания

updated_at - Дата обновления

Category (Категория)
name - Название категории

🌐 URL-маршруты
URL	Назначение	Имя
/	Главная страница	catalog:home
/contacts/	Контакты	catalog:contacts
/product/<id>/	Страница товара	catalog:product_detail
/product/add/	Добавить товар	catalog:product_add
/product/delete/<id>/	Удалить товар	catalog:product_delete
